# Contributing

Thanks for helping improve **One-Click Snippets**!

## Development setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run tests to verify your changes:
   ```bash
   npm test
   ```

## Guidelines

- Keep pull requests focused and include tests when possible.
- Code resides in plain JavaScript; please follow existing style.
- New UI strings should remain short and clear.
- If you add a feature or fix a bug, update the README when relevant.

Feel free to open an issue or draft PR if you have questions.
